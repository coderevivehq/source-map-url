# source-map-url documentation

source-map-url is a compatibility-focused utility for Node.js build tools and browser scripts that need to inspect or update JavaScript and CSS `sourceMappingURL` comments. It keeps the original package's four helper methods and UMD distribution while avoiding matches inside quoted string content.

1. [Install source-map-url](installation.md).
2. Follow the [Usage guide](usage.md) for a complete first example.
3. Consult the [API reference](api.md) for the supported helper methods.
